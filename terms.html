YouTube Manager TMCP 이용조건

시행일: 2026년 10월 24일

YouTube Manager TMCP는 본인의 YouTube 채널을 관리하기 위한 개인용 Termux MCP 도구로서 현재 개발 준비 중입니다. 이 공개 사이트에는 회원가입 또는 실제 채널 인증 기능이 없습니다.

1. YouTube 약관

이 프로그램을 사용하여 YouTube에 접근하거나 YouTube API Services를 이용하는 사용자는 YouTube 서비스 약관을 준수하고 이에 구속되는 것에 동의해야 합니다. 필요한 경우 YouTube API Services 이용약관도 적용됩니다.

2. 인증과 사용자 통제

사용자는 Google OAuth로 권한을 직접 부여하며, 해당 권한은 Google 계정 연결 관리에서 언제든 철회할 수 있습니다. 영상의 업로드·변경·삭제와 공개 상태 전환은 사용자의 지시와 승인 범위에서만 실행하도록 설계합니다.

3. 데이터 처리

개인정보 접근·이용·보유·삭제 및 외부 전송은 개인정보처리방침을 따릅니다. 이 문서는 도구 기능이 실제 구현되면 그 기능과 일치하도록 개정합니다.

4. 운영자 문의

GitHub Issues를 통해 문의할 수 있습니다.
