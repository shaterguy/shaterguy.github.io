개인정보처리방침

시행일: 2026년 10월 24일 · YouTube Manager TMCP

YouTube Manager TMCP(이하 “도구”)는 운영자가 개인 YouTube 채널을 관리하기 위해 Termux에 설치하는 개인용 MCP 프로그램입니다. 아직 개발 중이므로 아래 내용은 실제 기능 도입에 따라 갱신됩니다. 구현되지 않은 기능이 현재 사용자 데이터를 처리한다는 의미는 아닙니다.

1. 처리하는 Google 데이터

운영자가 직접 Google OAuth로 승인한 범위에서만, 채널 ID와 기본 정보, 동영상 ID·제목·설명·태그·공개 상태·썸네일·자막·재생목록 정보, YouTube 조회수·시청시간·유입경로·시청 유지율·구독자 관련 통계, 사용자가 지정한 댓글·답글, 인증에 필요한 접근·갱신 토큰을 처리하도록 설계합니다. 필수 기능과 무관한 Google 계정 자료는 요청하지 않습니다.

2. 데이터 이용 목적

동영상 게시·수정·삭제·예약, 채널 및 댓글 관리, 시청 성과 분석, 중복 게시 방지, 작업 수행 여부 확인을 위해 사용합니다. 사용자가 지시하지 않은 외부 게시나 계정 변경을 수행하도록 설계하지 않습니다.

3. 저장·공유·외부 전송

  • OAuth 자격정보는 공개 GitHub 저장소나 웹사이트가 아니라 운영자 개인 Termux의 접근 제한된 저장 영역에 보관하도록 설계합니다.
  • 작업 기록과 분석자료는 운영자의 로컬 기기 또는 승인된 개인 Google Drive 저장 영역에 보관할 수 있습니다.
  • Google API 이용을 위한 데이터가 Google에 전송됩니다.
  • 운영자가 ChatGPT 등을 통한 분석을 요청하면 그 요청에 필요한 채널 정보와 분석 결과가 해당 AI 서비스에 전달될 수 있습니다. 그 서비스의 데이터 처리에는 별도 정책도 적용됩니다.
  • Google 사용자 데이터는 판매하거나 광고 타기팅에 사용하지 않습니다.

4. 보유 기간 및 삭제

구현 후 OAuth 토큰은 연결이 유지되는 동안 저장하며, 운영자가 연결을 해제하거나 도구를 제거할 때 로컬 자격정보를 삭제하도록 구성합니다. 작업 로그와 분석자료는 운영·검증에 필요한 기간 동안 보관하고 운영자의 삭제 요청에 따라 정리할 수 있도록 구성합니다. 제작 중 생성된 대용량 임시 파일은 프로젝트에 정해진 정리 정책에 따라 처리합니다. 구체적인 보존 기간은 실제 구현 완료 시 명시합니다.

Google 접근 권한은 Google 계정의 제3자 연결 관리에서 철회할 수 있습니다. Google 권한 철회와 운영자 저장 데이터 삭제는 별도의 작업입니다.

5. 보안 조치

인증정보를 공개 페이지, 공개 소스코드 또는 로그에 포함하지 않습니다. 기능별 최소 OAuth 범위를 요청하고, 수정·게시 전에 대상 채널을 검증하며, 인증정보를 메인 Google Drive 자동화와 분리하여 관리하도록 설계합니다.

6. 이 웹사이트의 데이터

본 사이트는 GitHub Pages에서 제공하는 정적 웹페이지입니다. 별도의 방문자 추적 스크립트, 광고 또는 Google 로그인 기능을 설치하지 않았습니다. GitHub의 기본 서비스 운영 과정에서 접속 기록이 처리될 수 있습니다.

7. Google API Services User Data Policy

Google API의 사용자 데이터는 Google API Services User Data Policy와 적용 가능한 Limited Use 요건을 준수하는 방식으로 처리할 예정입니다. 실제 기능·데이터 흐름이 변경되면 본 방침을 갱신합니다.
